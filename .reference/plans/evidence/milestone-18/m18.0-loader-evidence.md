## What was built

Fixes the "only 2 of 20 load" problem at both roots:

- **Recursive discovery.** `scanSkillDir` walks the tree (≤4 deep), so skills
  may sit at the root or under categories (`<root>/<category>/<name>/SKILL.md`).
  A skill is any directory containing `SKILL.md`; its frontmatter `name` must
  equal the directory name. The descriptor now carries `path` (relative dir) and
  `category`. Symlinked entries are **skipped**, never followed.
- **Tolerant frontmatter.** `parseSkillFile` reads only `name` / `description` /
  `version` and **tolerates** unknown keys, nested blocks (`metadata:`), list
  items, and stray lines. Duplicate *known* keys still fail closed.
- **Path-aware service.** `loadBody`, `updateSkill`, and `deleteSkill` resolve
  via the descriptor's `path`, so nested skills load, update, and delete
  correctly. `createSkill` writes flat at the root (still discovered).
