> Status: **verified** (2026-10-09). Slice **M18.1**. Per-slice evidence; M18 is
> in progress.

## What was built

- **Shipped collection:** the 98-skill library now lives at **`core/skills/`**
  (tracked; inside the compose build context, so it is baked into the image).
- **`SkillSeedService`:** on startup (and on demand) it copies shipped skills
  into `SKILLS_DIR_PATH`, **never overwriting** an existing file — user edits
  always win, and deleting a skill re-seeds it next run. Config:
  `SKILLS_SEED_ENABLED` (default true), `SKILLS_SEED_ROOT` (default the app's
  `skills/`). Documented in `.env.sample`.
- **Management surface:**
  - **Slash:** `/skills seed`, `/skills create <name> <description>`,
    `/skills delete <name>` (plus the existing list / show / refresh / use /
    drop / pull / suggest / active).
  - **API:** `POST /core/skills` (create), `DELETE /core/skills/:name`,
    `POST /core/skills/seed` (plus the existing list / discover / active / get).
