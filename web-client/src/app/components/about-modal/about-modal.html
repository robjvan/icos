ICOS web client

Chat and management UI for the ICOS stack (self-hosted, single user).

Chat, sessions, approvals, and clarifications are live against core. Skills, the memory ledger, MCP servers, models, and the secret vault are wired. Tabs without a server milestone yet render an honest placeholder.

The adapted skill files, and the inspiration for the tool files, come from Hermes Agent. Thank you to the Hermes project.
