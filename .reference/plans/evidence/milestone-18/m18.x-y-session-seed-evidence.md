# M18.x + M18.y — Session enable/disable + seed force: evidence

> Status: **verified** (2026-10-09). Slices **M18.x** and **M18.y**. M18 is now
> fully complete.

## M18.x — Per-session enable/disable

`SkillService` gained a session-scoped on/off:

- `setSessionSkillsEnabled(sessionId, enabled)` / `isSessionSkillsEnabled(sessionId)`
  (default on; the global `SKILLS_ENABLED` still wins).
- When off: no catalog block, no auto-discovery, and no pinned/one-shot
  injection for that session. `buildCatalogBlock(sessionId)` and
  `resolveTurnSkills(sessionId, …)` gate on it; the `sessionId` is threaded
  through the conversation context builders.
- Commands: `/skills on`, `/skills off`; `/skills active` shows
  `enabled: yes|no`.

## M18.y — Shipped-skill update path

`SkillSeedService.seed({ force })`:

- Default unchanged: **never overwrite** an existing file.
- `force: true` replaces existing files so an adapted shipped skill reaches a
  runtime copy that already exists (local edits to those files are lost).
- `SeedReport` gained `overwritten`.
- Surfaces: `/skills seed --force` and `POST /core/skills/seed {force:true}`.
