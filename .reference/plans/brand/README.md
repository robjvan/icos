# ICOS brand

The ICOS logo: a lowercase **i** — the stem is the evolving self, the dot is
the identity node. It is a monogram and a picture of the persona design at
once.

## Palette (Exile Research)

| Role | Name | Hex |
| --- | --- | --- |
| Background (dark) | smoky granite | `#25282A` |
| Main | hawkesbury | `#6F8F82` |
| Accent | kimirucha brown | `#8A6D3B` |
| Background (light) | lilac mist | `#E4E4E7` |

## Files

| File | What it is |
| --- | --- |
| `icos-mark.svg` | The bare monogram, transparent background (reusable anywhere). |
| `icos-app-icon.svg` | 512 px app icon / favicon source (smoky-granite tile, hawkesbury stem). |
| `icos-logo-dark.svg` | Presentation sheet on smoky granite (hero, lockup, sizes, app icon, on-light strip). |
| `icos-logo-light.svg` | Presentation sheet on lilac mist (same, with an on-dark strip). |

## Notes

- The **wordmark on light** uses smoky granite, not hawkesbury: hawkesbury on
  lilac mist is only ~2.8:1 contrast, which fails WCAG AA for text. The mark
  itself always carries hawkesbury + kimirucha brown.
- At **16 px** the bare monogram's dot can merge with the stem; prefer the
  inverted `icos-app-icon.svg` for favicons.
- No outline/monochrome variant yet — add one if a context needs a single ink.
